# Profile Card UI/UX Design
About the Project

This project is a Profile Card UI/UX Design created using HTML and CSS. It displays a profile section with social media icons, buttons, and engagement statistics in a clean layout.

# Technologies Used
HTML5
CSS3
Font Awesome Icons
# Features
Attractive profile card design
Social media icons
Subscribe and Message buttons
Likes, comments, and shares statistics
Rounded profile image
Box shadow and styling effects
# Project Preview

The profile card includes a profile image, developer information, social media links, and engagement details.

# How to Run
Download or clone this project.
Keep the HTML file and profile image in the correct location.
Open the HTML file in your web browser.
Make sure you have an internet connection for Font Awesome icons.
